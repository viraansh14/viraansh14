# Viraansh Bhanushali

Builder of systems that run themselves. I work across AI infrastructure, spatial computing, native apps, and applied security, usually taking a project from first principles all the way to something deployed and running.

Most of what I build lives in private repositories. A short tour of the range:

### Healthcare
Currently full-time on an AI-enabled hospital management system for Indian hospitals: patient records, billing, pharmacy, and clinical workflow, built for a market where existing software is either legacy or absent.

### AI systems and autonomy
A personal operating estate that coordinates dozens of AI agents across machines: a capability layer with routing and memory, a cross-machine memory sync built on a git peer protocol, native and web control surfaces, and an air-gapped edge intelligence platform written in Rust. The throughline is durable, verifiable autonomy rather than one-off prompts.

### Spatial and hardware
An AR display glasses platform (Flutter app, on-device translation, a Meta Quest simulator for prototyping the experience), and [HoloBox](https://github.com/viraansh14/holo3d), a DIY volumetric display driven from a phone. I like problems where software has to meet physics.

### Native and product engineering
A native macOS front end in Rust over a local daemon, an intelligence dashboard, and full-stack operating platforms for real businesses in premium retail, from factory floor to head office. Next.js and TypeScript on the surface, typed services underneath.

### Systems and security
Embedded C for the Flipper Zero, network and system tooling, and a self-improving capability framework with an enforced action gate. I care about the boundary conditions: what happens when something fails, and whether the failure is honest.

### Writing
I publish long-form research and essays on Substack, mostly on AI systems, autonomy, and the places technology meets law and the real world.
